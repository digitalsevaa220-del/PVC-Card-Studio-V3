# Build Setup.exe without building on your PC

1. Create a GitHub repository.
2. Upload the complete project folder.
3. Open **Actions**.
4. Select **Build PVC Card Studio V3 Windows Installer**.
5. Click **Run workflow**.
6. Wait for the workflow to finish.
7. Open the completed run.
8. Download the artifact named `PVC-Card-Studio-V3-Setup-Windows-x64`.
9. Inside it is `PVC_Card_Studio_V3_Setup.exe`.

The installer is produced by a Windows cloud runner. It should still be tested on the target Windows 11 machine before production use.
